# PyREADY

Python 과목평가를 반복 연습하는 웹 서비스입니다.

## 기능

- 7개 분야, 총 113문항
- 10문제, 20문제, 30문제 또는 선택 분야 전체 문항 출제
- 무제한 또는 60분 제한시간
- 객관식·단답형 자동 채점
- 단답형의 공백·따옴표·딕셔너리/집합 순서 차이를 의미 기준으로 채점
- 원하는 문항만 즉시 채점하고 정답·해설 확인
- 서술형 작성 후 모범답안 비교
- 브라우저별 오답·북마크·최근 기록 자동 저장

별도의 로그인이나 개인정보 입력 없이 바로 사용할 수 있습니다. 학습 기록은
현재 브라우저의 `localStorage`에 저장됩니다. 다른 브라우저나 기기와
동기화하려면 별도의 인증·데이터베이스 서비스가 필요합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
npm run build
```

`main` 브랜치에 반영된 변경은 GitHub Actions를 통해
`https://ansrudwns.github.io/pyready/`에 자동 배포됩니다.

## 공개 저장소 주의사항

이 저장소에는 문제은행과 서비스 코드만 포함합니다. 문제 제작 과정에서
참고한 교재, 원본 실습 코드, OCR 결과, 출처 대조표는 포함하거나 커밋하지
마세요. `.gitignore`에도 해당 검증 산출물이 등록되어 있습니다.
